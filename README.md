# RigTune

Personal, 100% local Windows 11 optimizer tailored to one PC (i7-14700F, RTX 4070 Ti SUPER, 64 GB, 2× NVMe).
The full design lives in [`SPEC.md`](SPEC.md).

## Build & test

```bash
dotnet build
dotnet test
dotnet publish src/RigTune.App -c Release -r win-x64 --self-contained false
```

The executable lands in `src/RigTune.App/bin/Release/net8.0-windows10.0.22621.0/win-x64/publish/RigTune.exe`.

The app requires administrator rights (`app.manifest` → `requireAdministrator`). All state is stored in
`%LOCALAPPDATA%\RigTune\` (`settings.json`, `snapshots.json`, `history.json`) using atomic temp-file + replace writes.

## Layout

| Project | Purpose |
| --- | --- |
| `src/RigTune.Core` | Persistence, snapshot/rollback engine, audit log, restore points, host detection, Win32/NVAPI interop |
| `src/RigTune.App` | WPF-UI (Fluent dark) shell, MVVM view models, tray icon |
| `tests/RigTune.Core.Tests` | xUnit tests: snapshot round trips, atomic JSON storage, hardware parsers |

Registry round-trip tests that touch the real registry run only on Windows and only under an isolated
`HKCU\Software\RigTuneTest\{guid}` key, which is deleted afterwards. Platform-independent tests use in-memory fakes.

## Status

- **Phase 1 (done):** solution, UI shell + navigation, atomic JSON persistence, `SnapshotService` (registry / service /
  power / NVAPI DRS, true revert, Revert All), `AuditLogService`, `RestorePointService` (cooldown bypass, SR/WMI
  create, WMI enumerate), `HostProfileDetector`, live Dashboard.
- **Phase 2 (done):** `TweakEngine` with one handler per SPEC §4.1 action type; runners for registry (64/32-bit, bit
  operations), services, power (AC/DC, hidden settings, hybrid scheduler GUIDs), NVAPI DRS, DISM/BCD/WinRE, Task
  Scheduler, PCI MSI & interrupt affinity, Device Manager, network adapters/TCP, NTFS, WASAPI inspection and app-scoped
  timer resolution. Generic `IStateRunner` snapshots give features, tasks, devices, BCD and TCP globals the same exact
  revert as the registry. `Catalogs/tweaks.json` holds all 185 tweaks (generated by `tools/generate_tweaks.py`) and is
  validated by tests. Tweaks view: search, filter pills, Danger Zone switch, area presets, restore-point prompt,
  inspector drawer, Revert All.
- **Phase 3 (done):** System Care — cooldown-free restore points; 7 cleanup actions with pre-scan sizes (never follow
  junctions, skip in-use files, guard protected roots); Startup Apps via Task Manager-compatible `StartupApproved` flags
  (snapshotted, original entries untouched); Appx manager with a Safe / Optional / Protected classifier (protected
  packages hard-blocked in the service unless Danger Zone is on) and a `winget upgrade` updater with live console;
  status-first Repair & Recovery for devices, services and policies (no chkdsk/sfc). Every action is audit-logged.
- **Phase 4 (done):** App Optimizer — `Catalogs/apps.json` with all 38 non-AMD profiles / 118 actions (generated by
  `tools/generate_apps.py`); detection via paths + uninstall keys; per-cache size scan and safe cleaning (cookies/history
  always unchecked, "(signs you out)"); reversible toggles run through the tweak engine (browser policies, services,
  Task Manager-compatible auto-start incl. packaged StartupTasks, chrome://flags parallel downloading via Local State);
  per-app "While You Play" rules in `gamemode.json`; custom apps in `custom_apps.json`.
- **Phase 5 (done):** Game Mode & tray watchdogs — `SystemTrayManager` (dynamic tray menu, minimize-to-tray, clickable
  balloon notifications), Start-with-Windows via an elevated `\RigTune\AutoStart` logon task (`--minimized`),
  `RefreshRateWatchdogService` (per-monitor pinned targets, DisplaySettingsChanged/startup/Game Mode checks, 1-click or
  auto restore), `GameLibraryScanner` (Steam VDF/ACF, Epic, Xbox, EA app, Battle.net + allow/exclusion lists) and
  `GameModeService` (WMI process-start trace with 2 s polling fallback; High priority for the game; Below Normal + EcoQoS
  + low I/O for While-You-Play apps; RAM trim only under memory pressure; optional power plan; crash-safe session state
  in `gamemode.json` restored on exit, Stop or next start).
- **Phase 6 (done):** Disk Analyzer — parallel cancellable scanner with live progress, access-denied folders skipped,
  junctions never followed, Games/Media/Apps/System/Other breakdown and per-drive cache; `PathGuard` hard protection
  (Windows, WindowsApps, page/swap/hiberfil, System Volume Information, $Recycle.Bin, profile roots, drive roots,
  `..` traversal) plus "Important" locks in `disk_locks.json` that cover descendants and ancestors; every deletion is
  confirmed and goes to the Recycle Bin; offline Space Advisor (Steam `localconfig.vdf` LastPlayed, caches, temp,
  Windows.old, old Downloads, dormant games) grouped Safe to Remove / Check First / Keep.
- **Phase 7 (done):** Windows Update Drift Detector (all snapshot types, re-apply keeps the true original), Backups,
  Drift & History (drift diff, per-tweak revert + Revert All, searchable/filterable audit log, profile export/import),
  Dashboard drift card + optional on-launch check, shutdown/session-end cleanup, warnings-as-errors everywhere.
  See [`docs/ACCEPTANCE.md`](docs/ACCEPTANCE.md) for the SPEC §8 checklist.
